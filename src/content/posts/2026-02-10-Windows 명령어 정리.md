## 1) 기본 규칙(경로/환경변수/파이프)

### 1.1 경로

- 절대경로: `C:\Users\username\project`
- 상대경로: `.\src`, `..\..`
- 홈: `%USERPROFILE%` (CMD), `$HOME` (PowerShell)

```cmd
# CMD
cd                  # 현재 경로
cd C:\project       # 이동
cd ..               # 상위 폴더
cd /d D:\data       # 드라이브 변경 포함
```

```powershell
# PowerShell
Get-Location        # 현재 경로(또는 pwd)
Set-Location C:\project  # 이동(또는 cd)
cd ..               # 상위 폴더
```

### 1.2 환경변수

```cmd
# CMD
set                      # 모든 환경변수 보기
echo %PATH%              # PATH 출력
set MYVAR=value          # 임시 설정(현재 세션)
setx MYVAR value         # 영구 설정(재시작 필요)
```

```powershell
# PowerShell
$env:PATH                # 환경변수 출력
$env:MYVAR = "value"     # 임시 설정
[System.Environment]::SetEnvironmentVariable("MYVAR", "value", "User")  # 영구 설정
```

### 1.3 리다이렉션/파이프

- `>`: 덮어쓰기, `>>`: 이어쓰기
- `|`: 앞 출력을 뒤 입력으로

```cmd
# CMD
echo hello > a.txt
type a.txt | findstr "hello"
dir | more              # 페이지 단위로 보기
```

```powershell
# PowerShell
"hello" > a.txt
Get-Content a.txt | Where-Object { $_ -match "hello" }
Get-ChildItem | Out-Host -Paging
```

## 2) 파일/디렉터리 다루기

### 2.1 목록/이동/생성

```cmd
# CMD
dir                      # 목록
dir /a                   # 숨김 포함
dir /b                   # 파일명만
md test                  # 폴더 생성(mkdir도 가능)
md a\b\c                 # 중첩 폴더 한번에
```

```powershell
# PowerShell
Get-ChildItem            # 목록(또는 ls, dir)
Get-ChildItem -Force     # 숨김 포함
New-Item -ItemType Directory -Path "test"  # 폴더 생성
mkdir a\b\c              # 중첩 폴더 한번에
```

### 2.2 파일 생성/복사/이동/삭제

```cmd
# CMD
type nul > note.txt      # 빈 파일 생성
copy a.txt b.txt         # 복사
xcopy src dist /E /I     # 디렉터리 복사(/E: 하위포함, /I: 대상을 폴더로)
move a.txt docs\         # 이동(=이름 변경)
del a.txt                # 삭제
rmdir /s /q dist         # 폴더 삭제(/s: 하위포함, /q: 확인없이)
```

```powershell
# PowerShell
New-Item -ItemType File -Path "note.txt"  # 빈 파일 생성
Copy-Item a.txt b.txt                     # 복사
Copy-Item src dist -Recurse               # 디렉터리 복사
Move-Item a.txt docs\                     # 이동
Remove-Item a.txt                         # 삭제
Remove-Item dist -Recurse -Force          # 폴더 삭제
```

> `rmdir /s /q`나 `Remove-Item -Force`는 "정말 확실할 때만".
> 습관적으로 치기 전에 `dir`로 한 번 확인하는 버릇 추천.

### 2.3 파일/폴더 찾기

```cmd
# CMD
dir /s /b *.log          # 하위 폴더 포함 검색(/s), 전체경로(/b)
where python             # PATH에서 명령어 위치 찾기
```

```powershell
# PowerShell
Get-ChildItem -Path . -Filter "*.log" -Recurse
Get-Command python       # 명령어 위치 찾기
```

## 3) 파일 내용 보기/검색

### 3.1 보기: type / more / select

```cmd
# CMD
type file.txt            # 전체 출력
type file.txt | more     # 페이지 단위
```

```powershell
# PowerShell
Get-Content file.txt                    # 전체 출력(또는 cat)
Get-Content file.txt -Head 50           # 위 50줄
Get-Content file.txt -Tail 50           # 아래 50줄
Get-Content app.log -Wait               # 실시간 로그 보기(-Wait = tail -f)
```

### 3.2 검색: findstr / Select-String

```cmd
# CMD
findstr "ERROR" app.log                 # 포함 줄 검색
findstr /n "ERROR" app.log              # 라인 번호 포함
findstr /i "error" app.log              # 대소문자 무시
findstr /s /m "TODO" *.txt              # 하위폴더 포함, 파일명만
```

```powershell
# PowerShell
Select-String "ERROR" app.log                      # 기본 검색
Select-String "ERROR" app.log -CaseSensitive       # 대소문자 구분
Get-ChildItem -Recurse | Select-String "TODO"      # 재귀 검색
```

### 3.3 빠른 텍스트 처리

```cmd
# CMD
find /c /v "" < file.txt  # 줄 수 세기
sort names.txt            # 정렬
```

```powershell
# PowerShell
(Get-Content file.txt).Count              # 줄 수
Get-Content names.txt | Sort-Object       # 정렬
Get-Content names.txt | Select-Object -Unique  # 중복 제거
```

## 4) 프로세스/리소스

### 4.1 실행 중인 프로세스

```cmd
# CMD
tasklist                                  # 프로세스 목록
tasklist | findstr "node"                 # 특정 프로세스 찾기
```

```powershell
# PowerShell
Get-Process                               # 프로세스 목록
Get-Process | Where-Object { $_.Name -eq "node" }  # 특정 프로세스
Get-Process | Sort-Object CPU -Descending | Select-Object -First 10  # CPU 상위 10개
```

### 4.2 종료

```cmd
# CMD
taskkill /PID 1234                        # PID로 종료
taskkill /IM notepad.exe                  # 이미지명으로 종료
taskkill /F /IM node.exe                  # 강제 종료(/F)
```

```powershell
# PowerShell
Stop-Process -Id 1234                     # PID로 종료
Stop-Process -Name notepad                # 이름으로 종료
Get-Process node | Stop-Process -Force    # 강제 종료
```

### 4.3 시작/백그라운드 실행

```cmd
# CMD
start notepad.exe                         # 새 창에서 실행
start /B python script.py                 # 백그라운드 실행
```

```powershell
# PowerShell
Start-Process notepad.exe
Start-Process -FilePath "python" -ArgumentList "script.py" -NoNewWindow
```

## 5) 네트워크/연결

### 5.1 네트워크 정보

```cmd
# CMD
ipconfig                                  # IP 정보
ipconfig /all                             # 상세 정보
ipconfig /flushdns                        # DNS 캐시 초기화

netstat -ano                              # 연결 상태(PID 포함)
netstat -ano | findstr :3000              # 특정 포트 사용 프로세스
```

```powershell
# PowerShell
Get-NetIPAddress                          # IP 정보
Get-NetTCPConnection                      # TCP 연결 상태
Get-NetTCPConnection | Where-Object LocalPort -eq 3000  # 특정 포트
Clear-DnsClientCache                      # DNS 캐시 초기화
```

### 5.2 연결 테스트

```cmd
# CMD
ping google.com                           # 핑 테스트
tracert google.com                        # 경로 추적
nslookup google.com                       # DNS 조회

curl https://example.com                  # HTTP 요청(Windows 10+)
```

```powershell
# PowerShell
Test-Connection google.com                # 핑 테스트
Test-NetConnection google.com -Port 443   # 포트 연결 테스트
Resolve-DnsName google.com                # DNS 조회
Invoke-WebRequest https://example.com     # HTTP 요청
```

## 6) 시스템 정보

### 6.1 시스템 정보

```cmd
# CMD
systeminfo                                # 시스템 정보 전체
systeminfo | findstr /B /C:"OS"           # OS 정보만

ver                                        # Windows 버전
hostname                                   # 컴퓨터 이름
whoami                                     # 현재 사용자
```

```powershell
# PowerShell
Get-ComputerInfo                          # 시스템 정보(Windows 10+)
$PSVersionTable                           # PowerShell 버전
Get-WmiObject Win32_OperatingSystem       # OS 정보
```

### 6.2 디스크/메모리

```cmd
# CMD
wmic logicaldisk get name,size,freespace  # 디스크 용량
```

```powershell
# PowerShell
Get-PSDrive                               # 드라이브 목록
Get-Volume                                # 볼륨 정보

# 폴더 크기
Get-ChildItem -Path . -Recurse | Measure-Object -Property Length -Sum

# 메모리 정보
Get-WmiObject Win32_PhysicalMemory | Measure-Object -Property Capacity -Sum
```

## 7) CMD vs PowerShell 비교

| 작업 | CMD | PowerShell |
|---|---|---|
| 현재 경로 | `cd` | `Get-Location` 또는 `pwd` |
| 목록 | `dir` | `Get-ChildItem` 또는 `ls`, `dir` |
| 파일 내용 | `type` | `Get-Content` 또는 `cat` |
| 검색 | `findstr` | `Select-String` |
| 프로세스 목록 | `tasklist` | `Get-Process` |
| 프로세스 종료 | `taskkill` | `Stop-Process` |
| 환경변수 | `%PATH%` | `$env:PATH` |
| 도움말 | `command /?` | `Get-Help Command` |

**권장사항**:
- 간단한 작업(파일 목록, 복사, 이동): CMD가 빠름
- 자동화/스크립팅/복잡한 필터링: PowerShell이 강력함
- 최신 윈도우 개발환경: PowerShell 익히기 추천

## 8) 한 장 치트시트

### 8.1 자주 쓰는 조합

| 목적 | CMD | PowerShell |
|---|---|---|
| 현재 위치/목록 | `cd`, `dir` | `pwd`, `ls` |
| 파일 찾기 | `dir /s /b *.log` | `Get-ChildItem -Recurse -Filter "*.log"` |
| 내용 검색 | `findstr /s "키워드" *.txt` | `Select-String "키워드" *.txt` |
| 프로세스 찾기 | `tasklist | findstr "node"` | `Get-Process | Where Name -eq node` |
| 포트 확인 | `netstat -ano | findstr :3000` | `Get-NetTCPConnection | Where LocalPort -eq 3000` |
| IP 확인 | `ipconfig` | `Get-NetIPAddress` |
| 환경변수 | `echo %PATH%` | `$env:PATH` |

### 8.2 실수 방지 체크

- 삭제 전: `dir` 한 번 확인
- 경로 이동: 드라이브 변경 시 `/d` 옵션 사용 (`cd /d D:\`)
- 관리자 권한: 시스템 설정이나 특정 폴더 작업 시 "관리자 권령으로 실행"
- 환경변수 영구 설정 후: 터미널 재시작 필요
- PowerShell 스크립트: 실행 정책 확인 (`Get-ExecutionPolicy`)

### 8.3 유용한 단축키

- `Tab`: 자동완성
- `Ctrl + C`: 실행 중단
- `Ctrl + L` (PowerShell): 화면 지우기 (`cls` 또는 `clear`)
- `F7` (CMD): 명령어 히스토리
- `↑` / `↓`: 이전 명령어 탐색
